# Archived font source

The unused normal Bodoni Moda variable face is preserved here rather than in
`public/fonts/`, so it no longer ships in the site build. The current heading
family is Outfit, while the approved hero retains the Bodoni Moda italic accent.
The Bodoni Moda Open Font License remains in `public/fonts/Bodoni-Moda-OFL.txt`
alongside the used italic face.
